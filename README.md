# YADRO VM Manager

Веб-приложение для управления виртуальной машиной Debian 13 ARM64 через браузер.

Позволяет запускать, перезагружать и выключать виртуальную машину, а также работать с ней через Serial- и SSH-терминалы.

## Используемые технологии

- **Backend:** Python, FastAPI, QMP, WebSocket, Paramiko
- **Frontend:** React, JavaScript, Vite, xterm.js
- **Веб-сервер:** Nginx
- **Виртуальная машина:** QEMU 11.0.5, Debian 13 ARM64
- **Развёртывание:** Docker Compose

## Как устроен проект

Приложение состоит из frontend и backend, которые запускаются в отдельных Docker-контейнерах.

**Frontend** отвечает за веб-интерфейс: кнопки управления виртуальной машиной, отображение её состояния и терминал. Готовый сайт обслуживается через Nginx.

**Backend** написан на Python с использованием FastAPI. Он запускает QEMU и управляет виртуальной машиной через протокол QMP. Подключения к Serial и SSH передаются в браузер через WebSocket.

QEMU 11.0.5 собирается из исходного кода внутри Docker. При первом запуске автоматически скачивается образ Debian, создаётся виртуальный диск размером 10 ГБ и выполняется настройка системы через cloud-init.

- `scripts/build-image.sh` - вспомогательный скрипт для локальной подготовки образа.

## Запуск

Для запуска необходимы установленные **Docker** и **Docker Compose**, а также подключение к интернету.

Основная целевая система - Linux. QEMU запускается внутри Docker в режиме программной эмуляции TCG.

Рекомендуется выделить Docker не менее 4 ГБ оперативной памяти и иметь не менее 10 ГБ свободного места на диске.

**1. Клонировать репозиторий:**

```bash
git clone https://github.com/halmat123/Vm_debian.git
cd Vm_debian
```

**2. Собрать и запустить приложение:**

```bash
docker compose up --build
```

При первом запуске автоматически собираются необходимые компоненты и подготавливается виртуальная машина. Сборка QEMU может занять некоторое время.

**3. Открыть в браузере:**

http://127.0.0.1:8080

## Работа с приложением

После запуска откроется страница **YADRO VM Manager** с панелью управления виртуальной машиной и терминалом.

В панели управления отображается текущее состояние виртуальной машины и три кнопки:

- **Включить** - запускает Debian.
- **Перезагрузить** - перезагружает работающую виртуальную машину.
- **Выключить** - завершает её работу.

Ниже находится терминал с двумя режимами подключения:

- **Serial** - последовательная консоль. Позволяет наблюдать загрузку Debian, системные сообщения и работать с командной строкой.
- **SSH** - подключение к Debian по SSH. После загрузки системы можно выполнять команды непосредственно из браузера.

Для работы в терминале не нужно устанавливать дополнительные программы или отдельно настраивать SSH-подключение.

## Остановка приложения

Для остановки нажать `Ctrl+C` в терминале, где запущен Docker Compose, затем выполнить:

```bash
docker compose down
```

Виртуальный диск Debian и SSH-ключ сохраняются в Docker volume, поэтому при повторном запуске система использует уже подготовленные данные.


## Проверка

Проверены сборка и запуск через Docker Compose, загрузка Debian, управление виртуальной машиной и подключение через Serial и SSH.

Для проверки терминалов реализованы два автоматизированных теста:

- `backend/test_serial_ws.py` - проверка Serial через WebSocket.
- `backend/test_ssh_ws.py` - проверка SSH через WebSocket.

Оба теста выполняют команду `whoami` внутри Debian и проверяют, что результат соответствует пользователю `debian`.

Перед запуском тестов необходимо запустить приложение и включить виртуальную машину через веб-интерфейс.

**Проверка Serial:**

```bash
docker compose exec -e WS_BASE_URL=ws://frontend:80 backend python /app/test_serial_ws.py
```

**Проверка SSH:**

```bash
docker compose exec -e WS_BASE_URL=ws://frontend:80 backend python /app/test_ssh_ws.py
```
